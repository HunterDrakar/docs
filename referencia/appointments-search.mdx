---

```http
POST https://www.elimagenda.com.br/api/v1/appointments/search
```

Use para responder "este contato tem consulta marcada?" a partir de um telefone, por exemplo ao receber um `lead.created` ou um `appointment.reschedule_requested`.

**Escopo:** `appointments:read`.

**Limite:** 60 requisições por minuto por chave.

Cada busca fica registrada no Elim, com as consultas devolvidas (o telefone pesquisado não é gravado no registro).

<Note>
  **Por que `POST` e não `GET` com o telefone na URL?** Endereços de requisição ficam gravados em logs de servidores, proxies e ferramentas de monitoramento, dos dois lados. Um telefone na URL viraria um dado pessoal espalhado por logs que ninguém controla. No corpo, ele só trafega cifrado e não é registrado. Toda busca por pessoa nesta API segue essa regra.
</Note>

## Parâmetros

<ParamField header="Authorization" type="string" required>
  `Bearer elim_live_...`
</ParamField>

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

## Corpo

<ParamField body="phone" type="string" required>
  Telefone em qualquer formato brasileiro: `5511987654321`, `+55 (11) 98765-4321`, `11987654321`. Precisa ter de 10 a 13 dígitos, senão `422 ERR_INVALID_PHONE`. A busca encontra o paciente com ou sem o nono dígito.
</ParamField>

## Resposta `200`

<ResponseField name="data" type="array">
  Até 100 consultas de pacientes ativos com esse telefone, da data mais recente para a mais antiga. Sem consulta, `data: []`.

  <Expandable title="consulta">
    <ResponseField name="id" type="string (uuid)">
      Id da consulta no Elim.
    </ResponseField>

    <ResponseField name="status" type="string">
      `agendado`, `confirmado`, `cancelado`, `reagendado`, `pendente`, `compareceu` ou `faltou`.
    </ResponseField>

    <ResponseField name="unscheduled" type="boolean">
      `true` quando a consulta foi desmarcada.
    </ResponseField>

    <ResponseField name="scheduled_for" type="string | null">
      Data e hora em ISO 8601 com o fuso de Brasília (`-03:00`).
    </ResponseField>

    <ResponseField name="updated_at" type="string (ISO 8601)">
      Última alteração da consulta, em UTC.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash
curl -s -X POST https://www.elimagenda.com.br/api/v1/appointments/search \
  -H "Authorization: Bearer $ELIM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "phone": "5511987654321" }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "data": [
    {
      "id": "62f4d14e-94ce-4bd2-8365-c89811fee8b2",
      "status": "agendado",
      "unscheduled": false,
      "scheduled_for": "2026-10-21T09:30:00-03:00",
      "updated_at": "2026-10-17T18:20:44.031Z"
    }
  ]
}
```

</ResponseExample>

## Erros

| HTTP | Código |
| --- | --- |
| `400` | `ERR_INVALID_REQUEST`: corpo que não é JSON |
| `403` | `ERR_SCOPE_MISSING`: falta `appointments:read` |
| `422` | `ERR_INVALID_PHONE`: `phone` ausente ou fora de 10 a 13 dígitos |

Mais os [erros de acesso](/autenticacao#erros-de-acesso).
